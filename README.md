# 棋譜ノート

対局のあと、子供が自分で棋譜を書きとめるためのアプリ。
**うろ覚えでも書けること**だけを目的にしていて、対局機能や検討機能はありません。

外部ライブラリなし。中身は `index.html` 1ファイルで、あとはオフライン用の付属品だけです。

## 使いかた

1. **自分＝先手／後手** を選ぶ（後手を選ぶと盤がひっくり返ります）
2. 一手ずつ入れていく。入れかたは2通り
   - **「この手だった？」の3択を押す** — 一番速い。当たらなければ「他の手」で次の3つ
   - **盤を直接押す** — 駒 → 行き先の順。行ける場所が緑の点で出る
3. どうしても思い出せない手は **「？」** を押して、そのまま先に進む
4. 後で上の帯の `？` の札を押して **「訂正」** で埋める
5. **「保存」** → 結果を選ぶと KIF ファイルになる

書いた手は**一番上の帯**に短冊で並びます。押すと訂正・削除ができます。

**どちらの番か**は盤の上下の帯で分かります。上が相手、下が自分で常に出ていて、
指すほうだけが塗られます（先手は黒、後手は白）。位置と色と文字の3つが同時に変わるので、
盤を見ているあいだも目に入ります。3択のボタンも同じ色になるので、
いま誰の手を選んでいるのかが手元でも分かります。

**この帯が駒台をかねています。** 持ち駒はここに並びます。打つときは帯の駒を押してから、
置く場所を押します。盤をひっくり返すと上下も入れ替わります。
上の帯に載る側の駒は、盤の駒と同じように下向きになります。枚数だけは向きを戻して読めるようにしています。

直前に指した手は、マスを塗らずに**その駒の縁を朱色で光らせます**。
長く見るものなのでベタ塗りより目が疲れにくく、駒の形もそのまま見えます。

盤は `0 2px 8px rgba(0,0,0,.08)` の影で紙から浮かせています。
影のぶんの余白（8px）は盤の左と下に取っています。右と上は筋・段の数字の余白を使い回すので、
盤の大きさは1マスぶんも減りません（430px幅で45px→44px）。

## 玉を取ったら終わり

王手放置はそのまま書けます（実際にそう指した対局を記録するため）。
ただし**玉を取った時点で対局は終わり**なので、そこから先は手を足せません。

- 「▲先手の勝ち」と出て、3択の代わりに保存ボタンが出ます
- 盤の上下の帯は、勝ったほうが「の勝ち」になります
- 結果が先に入るので、保存のときに選び直す手間がありません
- KIF は玉を取った手で終わり、`まで◯手で先手の勝ち` が付きます。
  投了ではないので `投了` の行は書きません
- まちがえて入れた場合は「戻る」で戻せば、続きが書ける状態に戻ります

相手が王手を受けていない局面では、**玉を取る手が3択の1番目**に出ます。
駒の値打ちで並べているので、玉を取る手が自然といちばん上に来ます。

駒台を盤の横ではなく上下に置いているのは、盤をできるだけ大きくするためです。
横に置くと駒台と段の数字で3マスぶんの幅を取られますが、上下なら盤が横幅いっぱいに使えます。
430px幅の端末で1マス34px→45px（盤306px→405px）になりました。

帯に載る駒の大きさは `layout()` の `fitHand()` が毎回決めています。
盤の駒の少し下（マスの0.80倍）を狙いつつ、**いま載っている種類数で
横に並べても折り返さない大きさ**に抑えます。折り返すと帯が二行になって、
そのぶん盤が小さくなるためです。持ち駒が2〜4種類なら盤の駒の95%、
7種類そろっても87%です。駒が隠れて押せなくなることはありません。

書いた内容はブラウザに自動保存されます。途中で閉じても消えません。

## 棋譜は貯まります

**「一覧」** に対局ごとの棋譜が並びます。押せばその棋譜に切り替わり、続きを書けます。
新しい対局は「＋ 新しい棋譜」から。**前の棋譜は消えません。**
消したいものだけ一覧から削除します。

一覧の上限は決めていません。ブラウザの容量（約5MB）まで入ります。
実測で80手の棋譜が974局（1局あたり約5.4KB）入りました。

### 名前をつける

一覧の各行の **「名前」** から、自分と相手の名前を入れられます。

- 一覧のタイトルが `そうた ー はるき` になります（未入力なら日付）
- 盤の上下の名札が「自分／相手」から名前に変わります
- 書き出す KIF の `先手：` `後手：` に入ります。自分＝後手なら自動で入れ替わります
- ファイル名に相手の名前が付きます（`kifu_20260805_1507_はるき.kif`）

自分の名前は次の新しい棋譜に引き継がれます。相手は毎回変わるので空から始まります。

### KIFに出したかの印

一覧の各行に、KIF で書き出した状態が出ます。

| 印 | 意味 |
|---|---|
| なし | まだ書き出していない |
| `KIF保存済` | 書き出し済みで、そのあと変えていない |
| `KIF保存後に変更` | 書き出したあとに手を足したり直したりした |

時刻ではなく**中身の指紋**（`sigOf()` の FNV-1a ハッシュ）で比べています。
そのため、書き出したあと一手足して「戻る」で消せば `KIF保存済` に戻ります。
棋譜を開いただけ、アプリを開き直しただけでは印は変わりません。

## ホーム画面に入れる

公開先はここです。

**https://kakugawari.github.io/kifu/**

スマホでこのURLを開いて「ホーム画面に追加」すると、アプリとして開きます。
一式がキャッシュされるので**対局場で電波が悪くても開けます**。

配信は GitHub Pages の「Deploy from a branch」で行っています。
どのブランチから配信するかは Settings → Pages で切り替えます。
`.github/workflows/test.yml` はテストを流すだけで、配信には関わりません。

ファイルを直接開く（`file://`）場合、アプリとしては動きますがオフラインキャッシュは効きません。
サービスワーカーが `file://` では登録できないためです。

## 思い出す仕組み

`suggest()` が局面から候補を並べます。エンジンは積んでいません。
子供の対局によく出る手を上に持ってくるだけの採点です。

| 上がるもの | 下がるもの |
|---|---|
| 直前に取られた駒を取りかえす手 | **指すと玉を取られてしまう手** |
| タダで取れる駒を取る手 | 相手に取られる場所へわざわざ動く手 |
| 成る手（とくに飛・角） | 中盤以降に玉が動く手（王手されているときは逆に上がる） |
| 王手 | 持ち駒を打つ手（少し） |
| 取られそうな駒を逃がす手 | |
| 前に進む手／序盤は定跡（7ライン） | |

### 玉が取られる手は出しません

王手されているのに気づかず別のところを指すと、次の手で玉を取られて負けです。
うろ覚えで書いているとき、そういう手が3択に混ざっていると**それを選んでしまいます**。

そこで候補ごとに「その手を指したあと、相手が玉を取れる形になるか」を実際に置いて調べ、
なる手は大きく下げます。並べるときも安全な手を全部先に出してから危ない手を足すので、
**1ページ目に危ない手が混ざることはありません**。

- 王手されている局面では上に「王手されています」と出ます
- 危ない手しか残っていないページには「玉を取られる手」と出ます
- それでも書きたい（実際にその手を指してしまった）ときは、「他の手」で送るか盤を直接押せば入れられます

実測（子供の対局を模した2592局面）で、3択に玉が取られる手が混ざる割合は
王手されている局面で **88.2% → 25.5%**（1ページ目に限れば 0%）になりました。
安全な手が3つに満たない局面は全体の1.5%、ひとつも無い（＝詰み）のは0.0%です。

**`？` を埋めるときだけ、別の見かたをします。**
その手より後の手がすでに入っていれば、「その手を入れたときに、後の手が全部そのまま指せるか」を最優先で見ます。
後ろが1手でも成立しなくなる候補は大きく下げるので、前後がつながる手が上に出ます。

候補は一度に3つ。当たらなければ「他の手」で次の3つに送れます。
同じ駒の手ばかり並ばないよう、ひとつの駒からは2手までにしています。

## 色の決めごと

将棋の約束どおり、**先手が黒、後手が白**です。

| 色 | 使うところ |
|---|---|
| 地 `#FAF9F6` | 画面の背景 |
| 黒 `#231D16` | 先手。名札、3択のボタン、棋譜の `▲`、「自分＝先手」 |
| 白 `#FFFFFF` | 後手。名札、3択のボタン、棋譜の札の地色、「自分＝後手」 |
| 朱 `#B23A2E` | まだ埋まっていない `？`、指せない手、「？」ボタン、直前の手の縁 |
| 水色 `#32C8F0` / `#A8F0FF` | 行き先の印だけ。外側と内側 |

地が白いので、白で示すもの（後手の名札、後手の棋譜の札）は地に埋もれます。
名札には黒い枠と影を、棋譜の帯と盤の面にはうっすら温かい地色を敷いて、
白が浮くようにしています。

文字と背景の組み合わせはすべてコントラスト4.5以上（小さい字も含む）にしてあります。

画面は上から**記録（棋譜の帯）／局面（盤の面）／入力（3択と操作）**の三層です。
帯は低い短冊、盤はうっすら白い面、3択は影の付いた厚いボタン、と役割ごとに形を変えて、
似た四角が並んで見えないようにしています。

一番押すのは3択なので、いちばん強い見た目にしてあります。
下の操作ボタン（戻る・？・保存・一覧）はいちばん控えめです。

## 駒の字

盤と駒台の駒は **Shippori Mincho Bold** で描いています。
端末のフォント任せだと見え方がばらつくので、駒に使う14文字だけを切り出して
`index.html` に woff2 として埋め込んであります（3.7KB）。オフラインでも同じ見た目になります。
書体の出どころとライセンス（SIL Open Font License 1.1）は `fonts/` を見てください。

## 保存

KIF形式（`#KIF version=2.0`）。将棋ソフトや棋譜再生サイトでそのまま開けます。
結果を選ぶと `投了` と `まで◯手で先手の勝ち` が付きます。

`先手：` `後手：` には一覧でつけた名前が入ります。入れていなければ `わたし` `あいて` です。

iPhone / iPad では共有シート（ファイル、LINE、メールなど）が開きます。
対応していないブラウザではファイルのダウンロードになり、本文のコピーも同時に行います。

**保存しなくてもアプリの中には自動で残ります。** 保存はアプリの外に出すための機能です。
ただしアプリ内の保存先はブラウザの記憶領域なので、ブラウザのデータを消すと一緒に消えます。
iOS の Safari でサイトとして開いているだけだと、7日間使わないと消える仕様（ITP）もあります。
残しておきたい棋譜は対局ごとに KIF で出しておくのが確実です。

## ファイル

| | |
|---|---|
| `index.html` | 本体。これだけで動く（駒のフォントも中に埋め込んである） |
| `manifest.webmanifest` / `sw.js` | ホーム画面追加とオフライン用 |
| `icon-*.png` / `apple-touch-icon.png` | アイコン |
| `tools/make-icons.js` | アイコンを作りなおすスクリプト（Playwright が要る） |
| `tools/make-koma-font.sh` | 駒のフォントを切り出しなおすスクリプト |
| `fonts/` | 駒のフォントの出どころとライセンス |
| `test/rules.test.js` | ルールと候補生成のテスト |

## 開発

```
node test/rules.test.js
```

DOM を使わない部分（`/* 状態 */` より前）を `index.html` から取り出して実行します。
合法手の数、定跡7ライン、二歩と行き所のない駒、「同」の表記と KIF、
取りかえしと `？` 埋めの並び順を見ています。
