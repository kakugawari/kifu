# 棋譜ノート

対局のあと、子供が自分で棋譜を書きとめるためのアプリ。
**うろ覚えでも書けること**だけを目的にしていて、対局機能や検討機能はありません。

`index.html` 1ファイルだけで動きます。外部ライブラリもサーバーも不要です。

## つかいかた

ファイルをブラウザで開くだけ。スマホなら「ホーム画面に追加」しておくと使いやすい。

1. **わたし＝先手／後手** を選ぶ（後手を選ぶと盤がひっくり返ります）
2. 一手ずつ入れていく。入れかたは3通り
   - **「この手だったかな？」の3択を押す** — 一番はやい
   - **「どの駒をうごかした？」で駒を選ぶ** — 候補がその駒の手だけになり、盤にも行けた場所が光る
   - **盤を直接タップ** — 駒 → 行き先の順
3. どうしても思い出せない手は **「わからない」** を押して `？` のまま先に進む
4. あとで棋譜の `？` をタップ → **「なおす」** で埋める
5. **「かきだす」** → 勝敗を選ぶと KIF ファイルになる

書いた内容はブラウザに自動保存されるので、途中で閉じても消えません。

## 思い出しの仕組み

`suggest()` が局面から候補を並べます。エンジンは積んでいません。
子供の対局によく出る手を上に持ってくるだけの採点です。

| 上がるもの | 下がるもの |
|---|---|
| 直前に取られた駒を取りかえす手 | 相手に取られる場所へわざわざ動く手 |
| タダで取れる駒を取る手 | 中盤以降に玉が動く手 |
| 成る手（とくに飛・角） | 持ち駒を打つ手（少し） |
| 王手 | |
| 取られそうな駒を逃がす手 | |
| 前に進む手／序盤は定跡（7ライン） | |

**`？` を埋めるときだけ別の見かたをします。**
その手より後の手がすでに入っていれば、「その手を入れたときに、後の手が全部そのまま指せるか」を最優先で見ます。
後ろが1手でも成立しなくなる候補は大きく下げるので、前後がつながる手が上に出ます。

候補は一度に3つ。当たらなければ「ほかの手」で次の3つに送れます。

盤全体だと合法手は中盤で130手前後ありますが、駒の種類で絞ると中央値9手まで減ります。
「５六に行った」は忘れていても「銀が出た」は覚えている、という前提の作りです。

## かきだし

KIF形式（`#KIF version=2.0`）。将棋ソフトや棋譜再生サイトでそのまま開けます。
勝敗を選ぶと `投了` と `まで◯手で先手の勝ち` が付きます。

iPhone / iPad では共有シート（ファイル、LINE、メールなど）が開きます。
対応していないブラウザではファイルのダウンロードになり、本文のコピーも同時に行います。

## 開発

ルール部分と候補生成のテスト:

```
node test/rules.test.js
```

DOMを使わない部分（`/* 状態 */` より前）を `index.html` から取り出して実行します。
